A regional state system I worked with spent Q2 mapping documentation maturity across the org chart. The pattern was consistent enough across four campuses to name.

Aid offices operated at the highest maturity because Title IV required it. IT operated close to that level because cyber underwriters required it. Everything else — registrar, bursar, advancement, IR, marketing — operated at whatever maturity the last audit finding had forced.

Maturity tracked external regulatory pressure with near-perfect fidelity. Where there was no external forcing function, there was no documentation.

The consequence wasn't hypothetical. The same operational failures repeated across the low-maturity functions on every campus. CMO transitions reset brand standards. Major-gifts departures reset pipelines. IR vacancies reset data definitions. Each function was rebuilding rather than compounding.

The state system was running on a regulatory-priority documentation model. Nobody had ever proposed the operational-priority alternative because nobody had named the current one.
